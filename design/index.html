myMethod is O(n³) when data is a LinkedList.

The outer loop runs 2n times and calls foo(data) each time.

Inside foo, the loop runs n times and calls lst.get(i). On a LinkedList, get(i) walks the list, so it costs up to n steps.

That makes foo O(n²), assuming hiddenMethod is O(1). Multiplying by the 2n outer calls gives O(n³).

With an ArrayList, get(i) is O(1), so the same code would be O(n²).
